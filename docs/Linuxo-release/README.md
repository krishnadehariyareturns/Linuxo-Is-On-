# Linuxo — Release Invitation

A static, black-and-white release invitation for the Linuxo Discord bot.

Release:
- Date: 15 September 2026
- Time: 7:00 PM IST
- Launch link placeholder: `____`

## Run locally

No build step is required. Open `index.html` in a browser, or serve the directory with any static server.

Example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Customize

Replace both `href="____"` values in `index.html` with the actual launch URL.

The page uses Anime.js 3.2.2 from jsDelivr. If you want a completely offline package, download Anime.js into the project and change the script tag to a local file.

## Prototype content shown

- Complex structured logging system
- `/startup` command
- Terminal-inspired Linuxo identity
- Startup diagnostics / command registry concepts

The page is frontend-only and contains no backend or secret credentials.
